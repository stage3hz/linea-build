# Тестовый стенд ПК-версии

Запускает **настоящую** ПК-версию (Electron) на Linux против **своего локального** сервера, без продакшена и без чужих аккаунтов.

- `setup.sh` — локальный тестовый CA и сертификат `api.invizent.com`, доверие в NSS, запись в `/etc/hosts` (только на тестовой машине).
- `tls-front.mjs` — HTTPS 443 → локальный сервер 3001 (с WebSocket). TLS-проверка в приложении **не отключается**: доверие идёт через тестовый CA.
- `run.sh` — отдельная D-Bus сессия + gnome-keyring, чтобы защищённое хранилище ОС работало как на десктопе (без «basic_text»).
- `seed-accounts.mjs` — два тестовых аккаунта (`tester`, `friend`).
- `electron-walk.cjs` — вход одним аккаунтом; `e2ee-walk.cjs` — две копии приложения переписываются через сквозное шифрование, включая сверку кодов.

Скриншоты — в `$STAND/shots`. Код приложения не меняется: адрес сервера тот же, что в сборке.
