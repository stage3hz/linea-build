# Линия 0.5.1: подготовка iPhone, приватность и бессрочная Platina

Это обновлённые исходники и сервер. Готовый подписанный IPA и новый Android APK 0.5.1 здесь не заявляются. Последний проверенный Android-бинарный файл относится к версии 0.5.0 и её отдельному снимку исходников.

## Изменения

- Подготовка iOS к EAS Build с управлением через iPhone и VPS: статические frameworks для LibSignal, профиль internal/preview и привязка к реальным данным владельца Expo. Собственный Mac для облачного маршрута не требуется; Xcode исполняется в EAS.
- Защитная проверка конфигурации против геолокации и совместных хранилищ приложений. Она проверяет финальные CNG-файлы, а не только исходный объект конфигурации.
- Явные запреты location/overlay и других ненужных Android-разрешений для будущей сборки.
- Настоящая бессрочная Platina: в базе отсутствует срок окончания, право связано с постоянным UUID. Для выдачи требуется доверенная серверная команда; публичного grant API нет.
- В профиле бессрочный статус подписан «Бессрочно». Эмодзи рядом с именем остаётся статичным; отсутствие даты без явного серверного признака не превращает старое значение в бессрочное.

## Размещение и использование

Полный порядок с iPhone — `tools/ios-cloud-setup/README.md`. Сервер — [DEPLOY_FROM_IPHONE.md](DEPLOY_FROM_IPHONE.md). Перед первой загрузкой новой серверной версии нужна резервная копия: схема базы мигрирует с 4 на 5. Старым сервером базу версии 5 открывать нельзя.

После регистрации аккаунта его текущий username используется для поиска UUID. Дальнейшая выдача выполняется именно по UUID. Команды и ограничения — [PLATINA_OWNER_0.5.1.md](PLATINA_OWNER_0.5.1.md). Реальный аккаунт владельца в этой сессии не создан и выдача ему не выполнена.

## Границы подтверждения

Публичный VPS, DNS, Expo/Apple-аккаунты и сертификаты не настроены. Архив Premium с подписью сейчас недоступен. Я не могу подтвердить пригодность подписи или успешный запуск iOS, пока не получены необходимые данные и не выполнены настоящие Pods/Xcode/signing/установка.

Фактические новые тесты и подготовка сборки — [PREPARATION_REPORT_0.5.1.md](PREPARATION_REPORT_0.5.1.md).
