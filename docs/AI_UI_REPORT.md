# AI: интерфейс, разрешение и состояние беседы

## Реализовано

Нижняя навигация содержит вкладку **AI** рядом с чатами, людьми, музыкой и профилем. В заголовке списка чатов есть отдельная кнопка быстрого вопроса: она открывает самостоятельный диалог AI. На узком экране нижняя навигация доступна также на страницах разделов. Чат с человеком не становится источником контекста AI.

`src/ai/AIScreen.tsx` предоставляет ввод текста, ожидание ответа, отмену, повтор последнего неуспешного вопроса, копирование ответа, имя реально ответившей модели и начало новой беседы. История живёт только в памяти текущего экрана. Закрытие, смена API/аккаунта или выход уничтожают сессию и разрешение; отдельного сохранения в AsyncStorage, файлы или историю мессенджера нет.

Перед первой отправкой виден переключатель **«Отправлять вопросы AI»**, по умолчанию выключенный. Текст объясняет передачу текущей AI-беседы через сервер в OpenRouter и поставщику модели, а также временное хранение истории в самом приложении. Есть ссылка на официальную [политику конфиденциальности OpenRouter](https://openrouter.ai/privacy). Приложение не утверждает, что удаляет данные у внешнего поставщика после закрытия экрана. Отмена явно останавливает ожидание, но не обещает отозвать уже переданный текст.

Запрос состояния — `GET /ai/status`. Если сервер сообщает `configured:false`, показано **«AI пока не подключён на этом сервере»**; отправка недоступна. Ошибка проверки имеет собственный повтор. Синтетических ответов, локального имитатора модели и платного запасного маршрута нет.

## Режимы и подтверждение задачи

Работают два режима: **Вопрос** и **Код**, только если соответствующая capability сервера включена. Код означает подготовку текстового кода или объяснения. Перед каждой новой задачей по коду открывается проверка точного запроса и количества сообщений контекста; весь предыдущий контекст можно раскрыть. Кнопка **«Отправить эту задачу AI»** подтверждает именно этот запрос. Если за время проверки сменились беседа или её владелец, подтверждение отклоняется и задачу нужно проверить снова.

Запуск кода, изменение файлов и публикация не запрашиваются. Это видно до подтверждения и включено в обозримый текст задачи. Код не исполняется и не записывается автоматически в пользовательские файлы. Повтор неудачной задачи повторяет уже рассмотренный запрос без создания второго пользовательского сообщения.

Карточки изображений, видео, 3D и соцсетей показывают `enabled/reason` из проверенного `/ai/status`. В этой версии у карточек нет исполнителя. Если сервер когда-либо начнёт сообщать доступность неподдерживаемого клиентом инструмента, клиент отдельно объяснит отсутствие поддержки этой версии и не выдаст фиктивный результат. При ошибке запроса статуса доступность считается неподтверждённой.

## Контракт и ограничения

Клиент отправляет только:

```json
{"messages":[{"role":"user","content":"вопрос"}],"consent":true}
```

Допустимы роли `user` и `assistant`. В payload не добавляются `system`, имена людей, переписки, файлы, выбранный клиентом провайдер, URL, модель или API-ключ. Контекст составляется из успешных предыдущих ходов этой AI-беседы и текущего явного вопроса. Неуспешные и отменённые запросы в контекст не попадают.

Согласованный серверный предел: 20 сообщений, 8000 единиц UTF-16 на сообщение, 32000 суммарно. Ответ принимается до 16000 единиц UTF-16. Служебная вводная задачи по коду учитывается в лимите. При превышении история не обрезается: пользователь получает предложение начать новую беседу. После особенно длинного ответа продолжение тоже может потребовать новой беседы, поскольку предел ответа больше предела одного входного сообщения.

Ответ должен содержать непустой `text`, фактическое `model`, `provider:"openrouter"`, `freeOnly:true`. Неполный ответ или отсутствие подтверждения бесплатного маршрута показываются как ошибка. Ключ остаётся на сервере. Настройка сервера и реальный вызов OpenRouter относятся к backend; UI сам не вводит и не хранит внешний API-ключ.

`AIConversation` создаёт `AbortController` и номер запроса. Отмена, отзыв разрешения, новая беседа и закрытие инвалидируют номер; поздний ответ или ошибка не возвращают старую историю. Параллельное второе нажатие Send не создаёт новый запрос. `Api.request` связывает сигнал с fetch, обрабатывает уже отменённый сигнал до сети; для AI root установил клиентский предел ожидания 70 секунд при серверных 60 секундах.

## Источники

- [Free Models Router](https://openrouter.ai/openrouter/free): официальный маршрут бесплатных моделей; в клиенте не задан конкретный платный fallback.
- [OpenRouter Privacy Policy](https://openrouter.ai/privacy): ввод передаётся внешней службе и поставщику модели; локальная очистка экрана не равна удалению у внешних получателей.
- Типы и лимиты согласованы с владельцем server AI. Сетевой контракт проверяется в `src/ai/conversation.ts`, вызовы API находятся в `src/ai/client.ts`.
