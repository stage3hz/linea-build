Чтобы продолжить, вставь этот файл в новый чат и напиши, что делать дальше. Весь код лежит в GitHub, поэтому новый чат начинает с `git clone`.

## 1. Что это

- **INVIZENT** (в приложении «Инвиз») — приватный мессенджер для друзей. Раньше назывался Linea (Линия).
- Клиент: Expo SDK 57 и React Native 0.86. Собственные нативные модули:
  - LineaSignal — libsignal для E2EE;
  - LineaPhoto и LineaVideo — очистка метаданных фото и видео.
- Хранилище на телефоне: SQLCipher.
- Сервер: Node 24, Fastify и SQLite, запускается через Docker Compose. HTTPS делает Caddy.
- Сквозное шифрование (Signal) соблюдается всегда: ответы, реакции, правки и закрепы передаются внутри шифротекста.
- **Правила проекта, от которых нельзя отступать:**
  - не отключать TLS, аутентификацию и шифрование;
  - не добавлять геолокацию и сканирование установленных приложений;
  - не спрашивать у пользователя пароли и приватные ключи;
  - не делать поддельных IPA;
  - не перекладывать программирование и отладку на пользователя.

## 3. Как собирать

**iPhone.** Сделать push в `main`, дождаться workflow, затем `git clone -b ipa-output https://github.com/stage3hz/linea-build`. В ветке лежит `INVIZENT-iOS-arm64-unsigned.ipa`. Пользователь сам подписывает её в GBox своим сертификатом. Мака у него нет.

**Android.** Собирается локально в контейнере:
```bash
cd mobile && npm ci
APP_ENV=development npx expo prebuild --platform android --clean --no-install
cd android && ./gradlew assembleRelease
```
- Нужны Android SDK и JDK 21.
- Maven Central отвечает 429, поэтому в `~/.gradle/init.d/` нужен init-скрипт с зеркалом `maven-central.storage-download.googleapis.com`.
- Если после prebuild пропал микрофон или камера, проверь `tools:node="remove"` в AndroidManifest.

**Тесты.** (`server`: 99 из 99)
- Клиент: `node --test --test-isolation=none test/*.test.mjs`. Тест `e2ee-native-interop` пропустить, ему нужен Gradle. Сейчас проходят 325 из 325.
- Сервер: `npm test` в папке `server`, проходят 98 из 98.

**Перед каждой сборкой** поднять версию сразу в нескольких местах:
- в `mobile/app.config.js`: поле `version`, строку `appVersion` в комментарии и `versionCode`;
- в `mobile/package.json`;
- в первых двух вхождениях `mobile/package-lock.json`;
- в `android/app/build.gradle`, если не делается prebuild `--clean`.

## 4. Сервер: полезные команды (`/opt/linea`)

- **Обновить файлы из GitHub:**
  `curl -fsSL https://codeload.github.com/stage3hz/linea-build/tar.gz/main | tar -xz --strip-components=1 linea-build-main/<пути>`
- **Применить изменения:** `bash install.sh` (повторный запуск безопасен).
- **AI (FreeLLMAPI):**
  - `bash deploy/ai.sh test` — проверить, что AI отвечает;
  - `bash deploy/ai.sh key <единый ключ>` — подключить единый ключ;
  - `bash deploy/ai.sh setup-code` — получить код первичной настройки.
- **Выход AI через Cloudflare Worker.** Провайдеры блокируют российский IP: Google отвечает «User location is not supported», OpenRouter — 403.
  - `bash deploy/relay.sh setup` — настроить заново;
  - `bash deploy/relay.sh pin` — если AI перестал отвечать: заново найти IP Worker'а через DoH;
  - `bash deploy/relay.sh off` — выключить выход через Worker.
  - Обычный DNS сервера не отдаёт адреса `*.workers.dev`, поэтому IP закрепляется в контейнере через `extra_hosts`.
- **Состояние AI:** работает через ключ Google AI Studio, модель `gemini-3.1-flash-lite`. Ключ OpenRouter отвечал 403, возможно, его нужно перевыпустить.

## 5. Что уже сделано

- Вход и регистрация, профиль, аватар.
- Три темы оформления, шрифт Montserrat, название «Инвиз».
- Новая иконка N и смена иконки: Настройки → Оформление (Синяя, Светлая, Контур, Сияние).
- Личные чаты с E2EE: фото, видео, файлы, аудио.
- Ответы, в том числе свайпом вправо. Пересылка, редактирование, удаление у себя и у всех, 12 реакций, закреплённое сообщение, поиск по чату, «печатает», галочки прочтения.

- Видеосообщения (кружки): запись до 60 секунд, круглый плеер.
- **Избранное**: заметки, файлы, голосовые, сохранение сообщений из чатов. Хранится только на устройстве в SQLCipher (ключ `saved:v1`).
- Настройки как в Telegram: оформление, размер текста, конфиденциальность (на сервере), данные и память.
- AI:
  - вопрос и код;
  - картинка, видео, озвучка, распознавание речи — если провайдер это умеет;
  - выбор модели;
  - история бесед хранится на устройстве (ключ `ai:v1`).
- Музыка (каталог Audius):
  - поиск с опечатками;
  - мини-плеер с кнопками предыдущий / следующий, убирается свайпом вниз;
  - экран «Сейчас играет».

## 6. Важные исправления (чтобы не наступить снова)

- **«file is not a database».** `withExclusiveTransactionAsync` в expo-sqlite открывает второе соединение без `PRAGMA key`. Запись в хранилище идёт на том же соединении: `BEGIN IMMEDIATE`, затем очередь (`e2ee/vault.native.ts`).
- **«Нет связи с сервером» при любой загрузке.** Глобальный fetch в Expo 57 — это expo/fetch, он не принимает части FormData вида `{uri,name,type}`. Загрузки отправляются собранным вручную multipart-телом: `multipartFile` в `api.ts`.
- **Android, `content://`.** Файлы из галереи сначала копируются в кэш приложения (`media/localCopy.ts`).
- **Android, клавиатура закрывает поле ввода.** При edge-to-edge `adjustResize` не работает, поэтому `KeyboardSafeView` сам добавляет отступ.
- **Тень на Android.** Elevation у полупрозрачного стекла рисовал серый прямоугольник. Elevation отключён.
- **Вылет при «Назад».** Recorder из expo-audio уже освобождён к моменту очистки. Не трогать его в cleanup без try.
- **Видео с фронтальной камеры iPhone.** Зеркальная матрица поворота теперь допустима (`LineaVideo VideoFormat.orientation`). Ошибки видео показывают код причины в квадратных скобках.
- **Микрофон на Android.** `microphonePermission:false` у expo-image-picker блокировал RECORD_AUDIO.
- **Поле ввода не уменьшалось после отправки.** Используется `ComposerInput`: высота берётся по `contentSize`, отступы там уже учтены.

- Android: «Защищённое видео не поддерживается» было ложным: `drmInitData` у обычных записей камеры и `getSampleFlags()==-1` в конце потока (`VideoTracks.kt`, `VideoAudio.kt`).
- Камера кружка: превью 3:4 обрезается кругом (квадратное растягивалось на Android); смена камеры только до записи.
