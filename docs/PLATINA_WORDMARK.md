# PLATINA — хромовая SVG-надпись

Для профиля Линии нарисована надпись **PLATINA** по двум JPEG-образцам пользователя со словом STAGE: вытянутые угловатые прописные, острые окончания, серебристый металл, светлые кромки и графитовые отражения. Это самостоятельные контуры букв, а не подключённый найденный шрифт. Точное название шрифта из образцов не установлено.

## Файлы

| Файл | Назначение |
| --- | --- |
| [platina-chrome.svg](../mobile/assets/branding/platina-chrome.svg) | Светлая внешняя кромка для тёмно-синей и чёрной тем |
| [platina-chrome-light.svg](../mobile/assets/branding/platina-chrome-light.svg) | Тёмная внешняя кромка для светлой темы |
| [create_platina_wordmark.py](../scripts/create_platina_wordmark.py) | Повторяемая генерация обоих SVG из исходных контуров |
| [PlatinaWordmark.tsx](../mobile/src/PlatinaWordmark.tsx) | Подключение локального ресурса в профиль |

Оба SVG имеют прозрачный фон, размеры 1600×520 и соответствующий `viewBox`. Внутри — векторные контуры, градиенты, clipping и мелкие векторные царапины. Нет встроенной фотографии, внешнего шрифта, внешних ресурсов, скриптов, SVG-фильтров или `foreignObject`. Надпись статична.

## Размещение

Надпись отображается только в карточке Platina собственного профиля. В списке чатов, заголовках переписок и списке людей логотип не добавляется. Статус подписки остаётся отдельным текстом, а возле имени пользователя отображается выбранный статус-эмодзи.

Компонент использует уже установленный `expo-image` и локальный `require()`, выбирает вариант по теме, сохраняет пропорции и имеет доступное имя `Platina`. Новая зависимость для SVG не добавлялась. На маленьком экране надпись может уменьшаться в доступной ширине.

## Проверка и границы

XML обоих ресурсов разобран; запрещённые для выбранного способа отображения элементы и внешние ссылки отсутствуют. В Inkscape получены и визуально проверены рендеры на чёрном и светлом фоне. Проверено уменьшение до ширины 220 px: слово читается, просветы двух A и отдельная I сохраняются, контуры букв не сливаются. Машиночитаемый результат: [platina-svg-validation.json](evidence-v05-build/platina-svg-validation.json).

PNG-превью показывает сам SVG на подложке; это не скриншот экрана приложения. Экспорт ресурсов и включение в Android APK проверяются отдельно в [BUILD_REPORT_0.5.md](BUILD_REPORT_0.5.md). Native-отрисовка на физическом Android/iPhone здесь не проверялась. SVG можно масштабировать без растрового увеличения, но его вид зависит от возможностей конкретного декодера.
