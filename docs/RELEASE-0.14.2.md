INVIZENT 0.14.2 для Windows, Android и iPhone с демонстрацией экрана в голосовых каналах игровых сообществ.

- Исправлена установка IPA: расширение ReplayKit теперь содержит обязательный `CFBundleDisplayName`. Добавлены регрессионный тест генерируемого Info.plist и проверка готовой IPA. Прежняя IPA 0.14.0 снята с загрузки после обнаружения ошибки установки в Simulator; она не заменяется молча под тем же именем.
- Windows сохраняет защиту от второго процесса: повторный запуск активирует существующее окно и не открывает второе локальное хранилище.
- Режимы 720p60 и 1080p60 задают целевое качество; на телефоне сохраняются пропорции экрана. Устойчивые 60 FPS не измерены. Системный звук не захватывается.
- Windows x64 EXE без цифровой подписи, Android arm64 APK с тестовым ключом шаблона (versionCode 28), iPhone arm64 IPA unsigned (iOS 16.4+). Для отправки экрана на iPhone нужны одинаковые App Groups в профилях приложения и расширения; Developer Mode их не даёт. Подпись через Appneza с нужными entitlements не подтверждена.
- Первый Windows-клиент пока не имеет полного соответствия нативному редактору фото и записи голосовых/видеокружков. Готовые аудиофайлы можно прикреплять, входящие голосовые воспроизводятся. WebM не отправляется под неверным MIME AAC/M4A.

Не проверены звонок и демонстрация между реальными устройствами, производительность POCO X6 Pro, устойчивый захват настоящего 1080p60, подписанная ReplayKit-трансляция и установка EXE на пользовательском ПК.
