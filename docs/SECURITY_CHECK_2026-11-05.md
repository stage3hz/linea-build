## Что нужно сделать на сервере

Обновить сервер, чтобы применились правила Caddy:

```
curl -sL raw.githubusercontent.com/stage3hz/linea-build/main/i.sh | bash -s api.invizent.com api2.invizent.com
```

Проверка после обновления (должно быть 404):

```
curl -s -o /dev/null -w "%{http_code}\n" https://ai.194-87-254-249.sslip.io/v1/models
```

- Перевыпущен ли единый ключ FreeLLMAPI после утечки в чате — не могу подтвердить.
- Порты сервера снаружи: исходящие соединения из среды проверки идут через прокси, результат недостоверен.
