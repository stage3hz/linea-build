# Запуск сервера Линии с iPhone

Этот порядок рассчитан на **новый VPS с Ubuntu 24.04 amd64**, публичным IPv4 и доступом администратора. Телефон служит для управления; API, база и файлы работают на VPS, в том числе когда телефон выключен. Режим разработчика iOS для серверной части не нужен. Публичный сервер в этой сессии ещё не создан.

Отдельный архив `linea-server-v0.5.1.zip` содержит сервер, Docker-конфигурацию и эту инструкцию. Внутри сразу расположены `server/`, `deploy/` и `docs/`, без дополнительной папки-обёртки. В архиве нет мобильного приложения, базы пользователей, сертификатов подписи iOS или заполненных секретов. Тесты, отчёты об их выполнении и инструкции сборки мобильного клиента, упомянутые в дополнительных документах, находятся в полном комплекте `linea-messenger-v0.5.1.zip`.

## 1. Подготовить VPS и домены

Для небольшого первого теста исходный ориентир проекта — **2 vCPU, 4 ГБ RAM, 40–60 ГБ SSD**. Это инженерная оценка, а не измеренная вместимость пользователей. Нужен тариф VPS/VDS с Docker и постоянным публичным IPv4. Обычный тариф размещения PHP-сайтов для этой конфигурации не подходит.

Например, у [Beget в панели VPS](https://beget.com/ru/kb/manual/virtual-servers) предусмотрены SSH, терминал и файловый менеджер, а среди готовых решений есть Docker. У [Timeweb Cloud](https://timeweb.cloud/docs/cloud-servers/manage-servers/console) есть веб-консоли. Удобство этих панелей именно в Safari на iPhone здесь не проверялось. Текущий тариф, включённый IPv4 и стоимость проверяйте до заказа.

Для запрошенной пары адресов `.ru` и `.com` подготовьте два домена и доступ к их DNS. Оба имени можно направить на один VPS. Дополнительный домен не является запасным сервером.

Выберите один основной адрес приложения: например, свой `api.<домен>.ru`. Второе имя останется адресом того же API. Не переключайте домен автоматически: локальное хранилище ключей клиента привязано к адресу сервера и аккаунту.

## 2. Подключиться с iPhone

Практический маршрут — панель провайдера в Safari для заказа и DNS, а [Termius](https://docs.termius.com/terminal/mobile-terminal.md) для SSH и передачи файлов. Наличие SFTP и условия выбранного тарифа приложения нужно проверить в своём аккаунте; бесплатность всех его функций не обещается.

В Termius создайте Host с IPv4 VPS, портом SSH из панели провайдера (обычно 22) и выданным именем пользователя. Для нового сервера далее предполагается `root`. Пароль или SSH-ключ вводите на своём устройстве. Сверьте отпечаток SSH-ключа сервера с данными провайдера при первом подключении.

Встроенный терминал провайдера — ещё один вариант выполнения команд, если он удобно открывается на телефоне. Для Beget есть и [браузерный файловый менеджер SPRUT.io](https://beget.com/ru/kb/manual/fajlovyj-menedzher), который поддерживает загрузку и распаковку архивов.

## 3. Загрузить серверный архив

Сохраните `linea-server-v0.5.1.zip` в «Файлы» iPhone. Согласно [официальной инструкции Termius для iOS](https://docs.termius.com/organize-and-connect-to-hosts/managing-files-with-sftp.md): удерживайте созданный Host, выберите **Connect via SFTP**, откройте `/root`, затем **Upload** и выберите архив.

Дальнейшие команды предполагают точный путь `/root/linea-server-v0.5.1.zip`. Выполняйте их в SSH-сеансе VPS. Если ваша учётная запись не root, используйте её домашний каталог и подходящий `sudo`; не копируйте root-пути без изменения.

## 4. Проверить Docker

```bash
docker --version
docker compose version
```

Если обе команды работают и сервер новый, переходите к распаковке. Если Docker уже используется другими проектами, сначала проверьте существующую конфигурацию и занятые порты 80/443.

Если Docker не установлен, ниже адаптация [официальной установки Docker Engine](https://docs.docker.com/engine/install/ubuntu/) именно для **Ubuntu 24.04 amd64 и root-сеанса**:

```bash
apt update
apt install -y ca-certificates curl unzip
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
chmod a+r /etc/apt/keyrings/docker.asc

cat > /etc/apt/sources.list.d/docker.sources <<'EOF'
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: noble
Components: stable
Architectures: amd64
Signed-By: /etc/apt/keyrings/docker.asc
EOF

apt update
apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
systemctl enable --now docker
docker compose version
```

Это не универсальные команды для любой ОС. Для другой системы или архитектуры используйте соответствующий раздел документации Docker. Все установки выполняются на удалённом VPS, не внутри iPhone.

## 5. Распаковать файлы

Для нового каталога установки:

```bash
apt install -y unzip
mkdir -p /opt/linea
unzip /root/linea-server-v0.5.1.zip -d /opt/linea
cd /opt/linea
```

Не распаковывайте этот первоначальный комплект поверх уже работающего сервера без резервной копии и отдельного плана обновления.

## 6. Настроить DNS и два адреса

В DNS-панели каждого своего домена добавьте запись `A`: имя `api`, значение — публичный IPv4 VPS. Если DNS обслуживается другой компанией, записи меняются у действующего DNS-провайдера. `AAAA` нужна только при настроенном и работающем IPv6.

В следующем блоке **сначала замените `api.example.ru` и `api.example.com` своими настоящими именами**. Это примеры, запускать получение сертификатов для них не нужно. Имена записываются без `https://` и без пути:

```bash
cd /opt/linea
umask 077
cat > deploy/.env <<'EOF'
PUBLIC_HOST_RU=api.example.ru
PUBLIC_HOST_COM=api.example.com
ALLOWED_ORIGINS=
USER_STORAGE_MIB=512
OPENROUTER_API_KEY=
EOF
chmod 600 deploy/.env
```

Для нативного приложения список browser CORS origins можно оставить пустым. Без отдельного серверного ключа OpenRouter вкладка AI будет показывать, что сервис не подключён. Ключ AI не нужен для запуска обычной переписки и не должен попадать в клиентский `EXPO_PUBLIC_*`.

## 7. Запустить и проверить

Убедитесь, что снаружи доступны TCP 80/443 и административный SSH. UDP 443 используется для HTTP/3. Публичный порт 3001 открывать не нужно: его обслуживает только внутренняя Docker-сеть.

```bash
cd /opt/linea
docker compose --env-file deploy/.env -f deploy/compose.production.yml config --quiet
docker compose --env-file deploy/.env -f deploy/compose.production.yml up -d --build
docker compose --env-file deploy/.env -f deploy/compose.production.yml ps
docker compose --env-file deploy/.env -f deploy/compose.production.yml logs --tail=100 api caddy
```

`config --quiet` проверяет конфигурацию, но не DNS или доступность интернета. После запуска и распространения DNS Caddy должен получить HTTPS-сертификаты. Условия выпуска и продления: [Automatic HTTPS](https://caddyserver.com/docs/automatic-https).

Откройте в Safari `https://ВАШ-ДОМЕН/health`, затем проверьте второе имя. Ответ должен сообщать, что сервер работает. После этого выберите основной HTTPS-адрес в приложении и проверьте настоящий обмен сообщениями между двумя устройствами. Проверка `/health` сама по себе не проверяет E2EE или доставку сообщений.

Если сертификат не выдаётся, проверьте A/AAAA, доступность портов 80/443 и журнал Caddy. Если API не становится healthy, посмотрите журнал API. Не отключайте HTTPS для обхода ошибки: распространяемый мобильный клиент требует его.

## 8. Резервные копии и обслуживание

```bash
cd /opt/linea
bash deploy/backup.sh /var/backups/linea
```

Этот скрипт кратковременно останавливает API, создаёт согласованную копию SQLite и файлов, затем запускает API снова. Он не настраивает расписание, не удаляет старые копии и не отправляет их на другое хранилище. Для защиты от потери VPS нужно отдельное защищённое хранилище и проверка восстановления.

Не выполняйте `docker compose down -v` на рабочем сервере: `-v` удаляет постоянные данные. Следите за свободным диском; квота одного аккаунта в 512 МиБ не ограничивает суммарное число аккаунтов. Уведомления APNS/FCM и звонки ещё не подключены.

## iPhone-приложение и подпись

Серверный ZIP не устанавливается как приложение на iPhone. Для реального интерфейса нужна собранная и подписанная iOS-версия. [Developer Mode](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device) разрешает запуск development-сборок, но не создаёт сборку или сертификат подписи. Для работы без собственного Mac подготовлен маршрут VPS → EAS Build → установка по ссылке на iPhone. Полный исходный комплект содержит `tools/ios-cloud-setup/README.md` и проверенный подготовщик. EAS использует удалённую macOS-машину; нужны ваш Expo-проект и подходящие Apple signing credentials с разрешением для устройства. В текущей передаче подписанный IPA и настоящий iPhone-скриншот не подтверждены.

Полная конфигурация и ограничения масштабирования: [DEPLOYMENT.md](DEPLOYMENT.md). Серверная E2EE-политика: [E2EE_ONLY_0.5.md](E2EE_ONLY_0.5.md).

## Бессрочная Platina владельца

После регистрации аккаунта оператор сервера может найти его UUID по текущему публичному имени и выдать бессрочное право через CLI. Оно сохраняется при смене имени, перезапуске и восстановлении пароля. Перед обновлением прежнего сервера до 0.5.1 нужна резервная копия: схема меняется с 4 на 5. Команды и проверки — [PLATINA_OWNER_0.5.1.md](PLATINA_OWNER_0.5.1.md). Реальным аккаунтам при подготовке комплекта право не выдавалось.
