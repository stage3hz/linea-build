Windows-клиент 0.14.1 и мобильные сборки 0.14.0 с демонстрацией экрана в игровых голосовых каналах.

- Windows 0.14.1: повторный запуск EXE активирует существующее окно; второй процесс не открывает локальное хранилище. Это предотвращает конкурирующую запись двух экземпляров приложения. Проверяется отдельным тестом с двумя настоящими процессами Electron.
- Android APK и iPhone IPA имеют версию 0.14.0 и совпадают с проверенными файлами предыдущего релиза. История исходников и опубликованные файлы 0.14.0 не переписывались.
- Демонстрация запрашивает 720p60 или 1080p60. На телефоне сохраняются пропорции дисплея. Фактические FPS/разрешение зависят от устройства и сети; устойчивые 60 FPS не измерены. Системный звук не захватывается.
- Windows x64 EXE без цифровой подписи; Android arm64 APK подписан тестовым ключом шаблона; iPhone IPA unsigned. Для отправки экрана на iPhone нужны совпадающие App Groups в профилях приложения и ReplayKit extension. Developer Mode этого не даёт, подпись с нужными entitlements через Appneza не проверена.
- Первый Windows-клиент пока не имеет полного соответствия нативному редактору фото и записи голосовых/видеокружков. Готовые аудиофайлы можно прикреплять; входящие голосовые воспроизводятся. Неверно маркированный WebM не отправляется под видом AAC/M4A.

Проверены TypeScript, 371 клиентский тест, 6 desktop-тестов, Windows DPAPI, Signal IPC, границы файлового кэша и получение кадра WebRTC-приёмником в обоих режимах, включая запуск кода из упакованного app.asar. В CI захватывалось окно 1008×680; это не измерение настоящего 1080p60. На macOS отдельно проверено закрытие сокета до подключения ReplayKit.

Не проверены звонок/демонстрация между реальными устройствами, производительность POCO X6 Pro, подписанная ReplayKit-трансляция и установка EXE на пользовательском ПК. Результат iOS Simulator будет указан после отдельной проверки.
