# Линия 0.5.0 — состав обновления

## Что входит

| Область | Реализация |
| --- | --- |
| Защита | Личные сообщения и вложения только E2EE; открытый режим сервера удалён. Release/preview требует HTTPS/WSS. Звонки пока не реализованы и допускаются только после проверки E2EE. |

| Брендинг | Векторная хромовая надпись PLATINA по двум присланным образцам: острые готические прописные, серебро и графит, прозрачный фон. Только в профиле; отдельная контрастная кромка для светлой темы. Контуры нарисованы для приложения, точное имя исходного шрифта не установлено. |
| Вложения | Компактная панель «Галерея / Аудио / Файлы», выбор нескольких вложений, редактор, обязательная подготовка фото/видео до шифрования. |

| AI | Отдельная вкладка и быстрый диалог для вопросов и кода; серверный маршрут только к бесплатным моделям с явным разрешением передачи AI-беседы. |

## AI и доступность

Администратор собственного сервера задаёт `OPENROUTER_API_KEY` только в серверном окружении. Этот ключ не включён в исходники или APK и не должен попадать в `EXPO_PUBLIC_*`. Без ключа вкладка показывает состояние «AI не подключён». Роут использует `openrouter/free`, нулевой предел цены и правила выбора провайдеров, исключающие разрешённое накопление данных. Живой ответ модели в этой сборочной среде не проверялся: сетевое поведение проверялось подставным контролируемым провайдером.

Бесплатная квота внешнего сервиса ограничена и может быть общей для пользователей одного серверного ключа. Безлимитные бесплатные вычисления не обещаются. Официальная документация: [free router](https://openrouter.ai/openrouter/free), [лимиты](https://openrouter.ai/docs/api_reference/limits), [выбор провайдеров](https://openrouter.ai/docs/guides/routing/provider-selection).

AI получает только введённый в этой вкладке текст и явно показанный контекст этой AI-беседы. Личные переписки, вложения, контакты и ключи шифрования не добавляются автоматически. Для генерации кода есть просмотр конкретной задачи перед отправкой; код не исполняется на устройстве или сервере.

Генерация/редактирование изображений и видео, работа с 3D-моделями и исполнитель задач в соцсетях пока не подключены и обозначены недоступными. Подключённый аккаунт соцсети сам по себе не должен давать будущему исполнителю право отправлять сообщения: потребуется конкретная задача, аккаунт, получатели/цели, разрешённые действия, срок и лимит. Сейчас приложение не выполняет таких внешних действий.

## Что остаётся отдельными этапами

- Приём реальных платежей Platina, верификация покупок, возвратов и продлений.
- Собственные наборы анимированных эмодзи, аватаров, баннеров, тем и рамок. Статичные Unicode-эмодзи не выдаются за сгенерированный авторский набор. Надпись PLATINA в этом выпуске статична.
- Каналы и их платные возможности, группы, звонки, истории, боты, push и другие пункты полного Telegram-паритета из `TELEGRAM_PARITY.md`.
- Дополнительные настоящие AI-исполнители и подключения выбранных соцсетей. Автоматизация не имитируется текстовыми ответами.
- Широкая матрица кодеков/HDR и тестирование на физических устройствах; нейросетевой апскейлер.
- Подписанная iPhone-сборка через Xcode/Apple Developer. Исходники iOS включены, установленный на iPhone релиз здесь не подтверждён.

Музыкальная реализация предыдущей версии — Audius и локальная библиотека — сохраняется. Каталоги Яндекс Музыки и SoundCloud, обход подписок и обещание «вся музыка без ограничений» в этот выпуск не добавлены.

## Развёртывание

APK — тестовая Android-сборка, работающая с собственным сервером Линии. Домен и публичный сервер автоматически не создавались. Для сервера остаётся инструкция `DEPLOYMENT.md` и конфигурация двух доменов. В production compose добавлен исходящий HTTPS-доступ API для обращения к AI; публичный порт API по-прежнему не открыт, вход идёт через Caddy.

Для управления сервером с iPhone есть отдельный архив `linea-server-v0.5.0.zip` и [пошаговая инструкция](DEPLOY_FROM_IPHONE.md). Он включает сервер и Docker-конфигурацию; мобильное приложение, тесты и секреты подписи находятся за границами этого небольшого комплекта.

К миграции схемы 3→4 нужно применить обычную резервную копию базы перед обновлением. Миграция сохраняет существующие аккаунты, сеансы, ожидающие восстановления и криптографические устройства. Назад старым сервером базу версии 4 открывать нельзя.

Подробная граница шифрования, отличие AI и критерии включения звонков: [E2EE_ONLY_0.5.md](E2EE_ONLY_0.5.md).
