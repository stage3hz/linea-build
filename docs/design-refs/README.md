# Design references

DESIGN.md files from [GradientDeck UI](https://ui.gradientdeck.com) (`/styles/{slug}/design.md`),
downloaded 2026-11-06. They describe how the original sites look; the designs belong to those sites.
INVIZENT uses them only as a reference for its own screens:

| File | Used for |
|------|----------|
| `linear.md` | «Чёрная» theme: surface steps, hairline borders, greys, 12 pt cards, monospaced technical line |
| `spotify.md` | Music screen: 6 pt covers, round artists, 24 pt section titles, white play button, pill search |
| `raycast.md` | Ctrl+K quick switcher: Ink/Obsidian/Graphite palette, 8 pt input, keycap hints in mono |

Brand accents (Linear's acid lime, Spotify green, Raycast coral) are not used.
