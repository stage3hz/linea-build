Предварительная версия INVIZENT 0.14.0: Windows-клиент и демонстрация экрана в голосовых каналах игровых сообществ.

- Режимы 720p / 60 FPS и 1080p / 60 FPS. На телефонах сохраняются пропорции дисплея. Это целевые параметры: реальные FPS и разрешение зависят от устройства и сети. Звук других приложений не передаётся.
- Windows x64: установщик EXE без цифровой подписи. Проверены запуск Electron, изоляция renderer, DPAPI и получение кадра в WebRTC-приёмнике в обоих режимах. В CI захватывалось окно 1008×680; настоящий захват 1920×1080 и стабильные 60 FPS не измерены. Расширенные инструменты редактора фото и запись голосовых/видеокружков ещё не имеют полного соответствия мобильной версии.
- Android arm64: APK 0.14.0, versionCode 27, штатный тестовый ключ шаблона. Совместимость обновления зависит от того, каким ключом подписана установленная версия.
- iPhone: настоящая unsigned IPA для arm64 с ReplayKit extension. Для отправки экрана нужны профили с одинаковым App Group у приложения и расширения. Developer Mode этого не даёт; подпись через Appneza с нужными entitlements не подтверждена.

Не проверены звонок/демонстрация между реальными устройствами, установка EXE на пользовательском ПК и производительность POCO X6 Pro. Визуальная проверка iOS в Simulator не выполнена.
