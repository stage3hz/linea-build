## Дополнение: только E2EE

По новому требованию удалён внутренний режим plaintext даже для регрессионных тестов; 16 транспортных тестов перенесены на synthetic ciphertext без изменения production-защиты. Два новых теста сначала выявили старый открытый путь, затем прошли; legacy downloads закрыты. Выполнен read-only аудит HTTP/WS, mobile отправки, identity pinning, миниатюр, кэша и AI-границы. Отдельно 2 падающих теста выявили HTTP в preview; введён обязательный HTTPS для release и явный opt-in только в dev runtime, все 3 проверки транспорта прошли. В сценарии старта setup больше не подставляет автоматически открытый LAN URL.

Общий мобильный запуск сначала дал 302/303: RNG-тест не внедрял новый необязательный native thumbnail dependency, поэтому Node пытался читать Expo TS под node_modules. Исправлен только тестовый адаптер для обычного text-файла; проверка отказа при недоступном CSPRNG сохранена. Финальный повтор записан отдельно. Это не сбой или отключение алгоритма шифрования.

## Пересборка после PLATINA

После добавления двух ресурсов и компонента изменён только заголовок `ProfileScreen`; остальные производственные входы совпали с полным проверенным снимком. TypeScript прошёл, повторный Expo-export включил оба SVG и дал 556/880/867 модулей для web/Android/iOS.

Первый incremental Android build остановился при чтении уже отсутствовавшего временного native symbol-файла. Очистка только его производного каталога выявила следующую ошибку: два поколения resource DEX одновременно определяли `androidx.autofill.R$attr`. Один архив был создан до новых ресурсов, второй после; DEX не идентичны. Полный итог второго сбоя найден в Gradle daemon log, потому что клиентский журнал оборвался раньше.

Общая ошибочная предпосылка — пригодность старого набора generated app outputs для нового набора ресурсов. Для следующей сборки назначен `:app:clean` и отдельный single-use Gradle с выключенным filesystem watching и одним worker. Production-код, версии зависимостей и общий кэш пакетов не менялись. Исходные ошибки сохранены в `evidence-v05-build/android-platina-first-symbols.txt`, `android-platina-second-client-incomplete.txt` и `android-platina-second-dex.txt`. Результат завершающей сборки — в [BUILD_REPORT_0.5.md](BUILD_REPORT_0.5.md).

Следующий clean build сообщил об успехе Gradle, однако независимая проверка обнаружила APK без `AndroidManifest.xml`, `resources.arsc` и ресурсов. Подпись не прошла проверку; этот файл не передавался как готовая сборка. Отдельный этап оптимизации ресурсов затем дал полноценный архив с обоими SVG, проверенными по байтам. При очередной сборке обнаружены временный файл в native libraries и несоответствие package в generated `MainActivity`/`MainApplication`; корректный `app.config.js` при этом не менялся. Поэтому финальный prebuild и сборка перенесены в отдельный каталог `/tmp` без старых native outputs. Причина повреждения производных файлов не установлена; сохранённые исторические OOM-счётчики сами по себе её не доказывают. Производственные входы сверяются с замороженным снимком из 165 файлов.

## Размещение с iPhone и настоящий снимок приложения

Подготовлены отдельный серверный ZIP и [инструкция для iPhone](DEPLOY_FROM_IPHONE.md): Safari для панели VPS/DNS, SSH/SFTP для файлов и команд, Docker Compose, два домена, HTTPS и резервная копия. Архив содержит 26 файлов; проверены CRC, наличие runtime inputs, совпадение серверных исходников с build-манифестом и синтаксис шести блоков Bash. Реального VPS, настройки DNS и запуска контейнеров в интернете не было.

После запроса настоящего снимка приложения генерация макетов остановлена. В среде отсутствуют Android emulator/system image и подключённые ADB-устройства; Mac/Xcode и iOS Simulator также недоступны. Веб-предпросмотр ранее остановлен после явного запрета URL политикой браузера. Скриншот работающего приложения не получен. Включённый у пользователя Developer Mode не заменяет сборку и подпись IPA; указанный архив Premium среди доступных вложений не найден и не исследован как signing package.

## Среда и границы

Локального git remote для проекта нет; commit/push на внешний репозиторий не выполнялись. Изменения передаются исходным архивом. Компиляция Kotlin/Java и экспорт JavaScript не являются проверкой Swift с iOS SDK либо прогоном на физическом телефоне. Конкретные итоговые команды, числа тестов и идентификаторы сборки приведены в `TEST_REPORT.md`.
