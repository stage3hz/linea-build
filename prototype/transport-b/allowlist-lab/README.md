# INVIZENT — локальный стенд «белого списка»

**Модель для тестирования, а не реальный белый список оператора и не имитация точных правил DPI.** Не подключается к сторонним сервисам и не использует production-секреты.

## Что тестируем

- **Обычная сеть:** тестовый клиент и API находятся в Docker-сети origin, сообщение идёт напрямую.
- **Режим разрешённых адресов:** ограниченный клиент находится только в сети allowed; API — только в другой, origin. Прямой IP API недоступен, но узел carrier подключён к обеим сетям. Через него передаются те же TLS-байты.
- **Нет доступных маршрутов:** отдельный Docker-клиент подключён только к третьей изолированной сети denied. Ни основной сервер, ни carrier недоступны: приложение не должно показывать ложную доставку.
- **Неверный TLS-сертификат:** клиент отклоняет его даже через carrier.
- **Повторы с одним clientId:** тестовый сервер хранит сообщение один раз.

Carrier — обычный TCP-посредник, **не WebRTC, не MAX, не VK, не Телемост и не WB Stream**. Его доступность не подтверждает доступности настоящего SFU в мобильной сети.

### Запуск без Docker (тест политики на Node)

Из корня проекта, с Node и openssl:

    node --test prototype/transport-b/allowlist-lab/allowlist.test.mjs

В этом режиме запрет прямого соединения задаётся политикой теста в памяти, а не реальной системой фильтрации.

### Запуск с настоящей сетевой изоляцией Docker

На отдельной тестовой машине или disposable CI-runner с Docker Compose и OpenSSL:

    bash prototype/transport-b/allowlist-lab/run.sh

Создаются три приватные сети internal=true; на хосте порты не публикуются. Запускаются три клиента: обычный (direct), ограниченный (reserve) и полностью отключённый (offline). Если прямой маршрут из сети allowed неожиданно доступен — тест завершается ошибкой. После прогона контейнеры, сети и временный сертификат удаляются. **Не запускать на действующем VPS.**

Подсети стенда 172.29.230.0/24, 172.29.231.0/24 и 172.29.232.0/24; при конфликте с другими сетями Docker требуется изменение подсетей и соответствующих тестовых IP.

## Ограничения модели

Не воспроизводятся DPI и списки конкретного оператора, DNS-инъекция, SNI/QUIC/TLS ClientHello фильтры, WebRTC/ICE/STUN/TURN, RTP, токены и правила видеосервисов, качество LTE и фоновый режим iOS. Этот тест проверяет **сетевую достижимость и логику выбора резервного пути**, а не завершённый этап B.
